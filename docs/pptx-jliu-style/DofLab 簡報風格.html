§ III.ii · Implementation

最小可運行的 Conv2D

import torch
import torch.nn as nn

# 一層卷積：3 通道輸入 → 16 個 3×3 濾波器
conv = nn.Conv2d(
    in_channels=3,
    out_channels=16,
    kernel_size=3,
    padding=1,
)

x = torch.randn(1, 3, 32, 32)
y = conv(x)
print(y.shape)  # [1, 16, 32, 32]

三個容易踩的坑

i.padding=1 才能讓 3×3 卷積保持空間尺寸不變
ii.out_channels 是「濾波器數量」，不是輸出通道數的隨機選擇
iii.權重初始化預設為 Kaiming，不必手動 reset

Observation

當我們把 CLIP 的視覺嵌入接到 LLM 上，模型獲得了「描述影像」的能力——但也獲得了「描述不存在事物」的能力。

§ 03 · Abstention

讓模型有權利說「不知道」

# 加一個 abstention token：
# 訓練時，當答案不確定就監督它輸出 [IDK]

logits = model(image, prompt)
probs  = logits.softmax(dim=-1)

if probs[idk_id] > tau:
    answer = "我看不清楚這張圖"
else:
    answer = decode(argmax(probs))

三個設計選擇

01τ 的校準必須在 held-out 資料上做
02IDK 不該與「拒答」混淆，要分為「視覺不清」與「題目超綱」
03SFT 階段就要見過 IDK，RLHF 才修不回來

A reading note

所謂「2½D sketch」

Marr 怎麼說

它不是 3D 模型，也不是純粹的 2D 影像——是一個以觀察者為中心、編碼了深度與表面朝向、但還沒有物體身分的中間表徵。

用今天的話翻譯：那是一張depth + normal的特徵圖，恰好是 self-supervised 視覺學習想自動長出來的東西。

我的眉批
SKETCH OF SURFACE NORMAL FIELD
"
Marr 提出 2½D sketch 不是為了完工，而是為了承認：理解一個場景，必須先承認自己站在哪裡看它。 — 我的讀書筆記，2026.03.14

§ Boilerplate

第一小時，請先跑得起這個

# 不論題目是什麼，先有：
# 1) 一個輸入  2) 一個模型  3) 一個輸出  4) 一個 UI

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class In(BaseModel):
    text: str

# 黑盒，可以是任何模型
def solve(x: str) -> str:
    return x[::-1]

@app.post("/run")
def run(body: In):
    return {"out": solve(body.text)}

三條鐵則

壹先有一條能跑的鏈，再考慮替換每一塊
貳輸入輸出的格式比模型本身更早 freeze
參UI 即使醜，也要在 demo 前 12 小時可用
