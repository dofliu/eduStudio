# dof-podium · 講壇風 / TED 感

> DofLab 個人風格 · 莫蘭迪冷灰全襯線 · 適用於研究發表、conference、keynote。
> 視覺氣質：**沉穩、克制、權威，把講者的話留為主角**。
> 與三條鐵則完全相容。

---

## 何時使用

| 場景 | 是否建議 |
|---|---|
| 學術 conference 簡報 | ✅ 首選 |
| Keynote / Invited talk | ✅ 首選 |
| 研究所論文進度報告 | ✅ |
| 業界演講 | ⚠️ 太冷靜，改用 dof-editorial |
| 課程教學 | ❌ 太疏離，改用 forest / journal |
| 讀書會 | ❌ 改用 dof-notebook |

## 色彩 token

| 用途 | Hex | pptxgenjs |
|---|---|---|
| 紙底 | `#EEEDE9` | `"EEEDE9"` |
| 墨 | `#18191C` | `"18191C"` |
| 次文灰 | `#8B8F95` | `"8B8F95"` |
| 髮絲線 | `#CFCFC9` | `"CFCFC9"` |
| 強調色 · 霧藍石板 | `#5A6B7A` | `"5A6B7A"` |
| 次強調 · 麻灰 | `#B8B0A4` | `"B8B0A4"` |

**用色原則**：
- 一張投影片最多出現 **3 種色**：墨、灰、藍石板
- 強調色僅用於：英文題眉、序號、URL
- 麻灰只在圖表或卡片背景出現
- **避免**任何亮色、漸層、陰影

## 字體

| 用途 | 字體 |
|---|---|
| 中文標題 / 內文 | 思源宋體 / Noto Serif TC |
| 英文 / 數字 | EB Garamond（標題用 Italic、內文用 Regular）|
| 程式碼 | Consolas |

**鐵則對應**：
- 內文 **20–24pt**（比 editorial 還要更大、更稀）
- 章節標題 **54–72pt**
- 封面大標 **96–112pt**
- 頁碼 / footer 14–16pt

## 頁型骨架

### Cover · 演講封面
- **比 editorial 更安靜**：無大序號、無 ribbon
- 題眉 `A talk by Jui-Hung Liu` italic 32pt 霧藍
- 大標題垂直置中、左對齊、96–112pt
- 副標英文斜體 32pt 灰
- 上方仍保留「Workshop / Conference 名稱」於 logo 右側
- 底部 meta：日期 + 城市 + 機構

### Roadmap · 提綱
- 題眉 `Outline`（英文 italic）
- 標題用提問句：「今天的四個提問」
- 兩欄 grid，序號用 `01 / 02 / 03 / 04`（不是 i / ii）
- 每項一句主標 + 一行副說明

### Content · 兩欄 + 引述
- 同 editorial 骨架，但：
  - col-head 改成英文 italic + 1pt hairline 下緣
  - pull-quote 引言用**較深的灰**（非黑）
  - 引述來源若是自己團隊，標 `— Working hypothesis, DofLab 2025`

### Code
- 程式碼底色 `#18191C`，文字 `#EEEDE9`
- 關鍵字用 `#B8B0A4`（不用亮色）
- 註解用 45% 白 + italic
- 旁邊「三個設計選擇」用 `01 / 02 / 03` 序號

### Exercise / Audience Question
- 大字 `Audience Question` 或 `Discussion` italic
- 用於 keynote 中段或結尾留討論時間
- 題幹用提問句，前綴 `思考` 灰色

### Summary
- 題眉 `Three Takeaways`
- 三欄、頂上 1pt 黑線
- 序號 `01 / 02 / 03` 英文 italic 56pt 霧藍
- 小標 36pt、說明 22pt 灰

### End-page · Thank you
- 大字 `Thank you.` italic 144pt 霧藍
- 中文金句 44pt
- 底部聯絡資訊：`jhliu@ncut.edu.tw · doflab.tw`

## 視覺裝飾規範

- **零裝飾**為原則：只允許 hairline + 文字 + 圖表
- **不**使用任何 emoji / icon / SVG 圖騰
- 圖表配色：墨 + 霧藍石板 + 麻灰，最多 3 色
- 影像若使用：black & white、加 1pt 邊框（霧藍石板）
- 不使用方框、不使用陰影、不使用圓角

---

## 物件最小化策略

每張目標 **≤ 10 個**物件，比 editorial 更少。
- 母片固定 6 個
- 內容區 2–4 個
- **務必**：所有 hairline 用 Text + fill，不用 Shape
