# font-sizes · 字體大小鐵則

所有主題通用。每次產生任何頁面前必讀一次，牢記後可跳過。

---

## ⚠️ 絕對禁區：內文絕不低於 18pt

| 主題 | 內文最小 | 理由 |
|---|---|---|
| Forest / Navy / Frieren / Naruto | **18pt** | 投影機距離可讀下限 |
| Journal / 所有 dof 系列 | **20pt** | 襯線字細，需更大才可讀 |

**唯一允許 < 18pt 的位置**：頁腳 / 頁碼 / 母片 hairline 標籤（9–14pt）

---

## QA 指令（每次產生後執行）

```bash
# 掃描所有 9–15pt（非頁腳層級的字體）
grep -n "fontSize: 9\b\|fontSize: 1[0-5]\b" slides.js
```

若出現結果，逐一確認是否為頁腳/頁碼，否則一律調升至 18pt（或 20pt）。

## 常見錯誤

| 錯誤 | 修正 |
|---|---|
| 小字塞更多內容 | 減少內容，不降字級 |
| 題眉用 13pt | 改 20pt，縮短文字 |
| 兩欄內文用 16pt | 改 20pt，若太擠換成條列 |
| 標籤 + 數字用 12pt | 改 20pt |
