# 字體大小最低標準(可讀性鐵則)

**簡報是給教室後排看的,不是文件。內文絕對不可低於 16pt,建議 18pt 起跳。**

---

## 為何要訂這條規則

教學投影片常見錯誤是「想把所有內容塞進一頁」,結果用 9–12pt 把版面填滿。
這在製作端的螢幕上看起來「資訊密度高、很扎實」,但實際在教室投影時:
- 後排學生(離螢幕 ≥ 5 公尺)完全看不到 12pt 以下的字
- 14pt 以下需要瞇眼,學生會直接放棄閱讀
- 投影片變成只有授課者自己看得到的小抄

**判準:如果一張投影片需要學生「湊近螢幕才看得到」,就是失敗。**

---

## 各元素的最小字體 pt

| 元素類型 | 最小 pt | 建議 pt | 備註 |
|---|---|---|---|
| 頁面主標題 | 28 | 32–40 | 章節大標、節標 |
| 副標題 / 區塊標題 | 20 | 22–24 | § 標題、卡片標題 |
| **內文 (body)** | **18** | **18–22** | **絕對下限,違反即重做** |
| 條列項目 | 16 | 18–20 | bullet / 編號列 |
| 表格內文 | 14 | 16–18 | Routh 表、對照表 |
| 圖表 caption | 12 | 14 | 圖下方說明 |
| 程式碼 (Consolas) | 12 | 14–16 | 等寬字較矮,可略小 |
| 公式 LaTeX 圖片 | — | — | 用高度控制,不用 pt |
| 頁腳 / 章節提示 | 10 | 11–12 | 例外允許 10,僅限純標記 |
| 頁碼 | 9 | 10 | 純標記,允許最小 |

## ❌ 禁止情況

```javascript
// ❌ 內文用 11pt — 後排完全看不見
slide.addText("Routh-Hurwitz 判別法的核心是把特徵多項式的係數...", {
  fontSize: 11,   // 嚴重違規
});

// ❌ 條列要點用 10pt
slide.addText("• 第一步:把係數排成 Routh 表", {
  fontSize: 10,   // 嚴重違規
});

// ❌ 為了塞下 8 個 bullet 把字體縮到 9pt
```

## ✅ 正確做法

```javascript
// ✅ 內文 18pt 起跳
slide.addText("Routh-Hurwitz 把特徵多項式的係數排成表格...", {
  fontSize: 18,
});

// ✅ 條列項目 18pt
slide.addText("• 第一步:把係數排成 Routh 表", {
  fontSize: 18,
});
```

## 內容太多塞不下時的處理優先序

1. **精簡文字** — 砍掉冗詞、改條列、用印刷符號(§/·/→)取代連接詞
2. **拆分成多頁** — 一個概念一頁,而不是塞滿
3. **改用版型** — `card-grid` 把長段落變成卡片
4. **最後才考慮放圖** — 用 LaTeX 公式 / 圖表取代文字
5. **永遠不允許**:縮小字體到 16pt 以下來塞內容

## 自我檢查清單(每頁完成前 QA)

寫完一頁,問自己三個問題:
1. **5 公尺測試** — 把預覽縮到 25%,內文還能讀嗎?讀不到 → 字太小
2. **講義測試** — 印成 A4 黑白講義,內文還清楚嗎?
3. **9/10/11 搜尋** — 程式碼裡有 `fontSize: 9`、`fontSize: 10`、`fontSize: 11` 嗎?
   - 有 → 檢查是否為頁腳/頁碼(可接受)或內文(必須改)

```bash
# 快速 grep 檢查
grep -n "fontSize: 9\b\|fontSize: 1[0-5]\b" slides.js
# 確認每筆都是頁腳、頁碼、表格內文、程式碼或圖表 caption
```

## 與 Journal 風格的相容

Journal 風格使用襯線字體(Noto Serif CJK TC + Georgia),襯線在小字時辨識度更差,字體大小應比黑體風格再大 1–2 pt:
- Journal 內文建議 **20pt** 而非 18pt
- Journal 條列建議 **18pt** 而非 16pt
- Journal 頁腳因字距加寬可維持 10–11pt
