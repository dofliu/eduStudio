# 程式碼頁 (code)

展示 Python / JS / MATLAB 程式碼 + 預期輸出 + 說明。

> **狀態**:骨架待補完整實作。

---

## 結構元素

- 頁面標題(節號 + 標題)
- 深色程式碼區塊(占版面 60–70%)
- 預期輸出框(灰底白字或方框,占版面 20%)
- 說明文字(底部,1–2 行)

---

## 關鍵注意事項

⚠️ **Consolas margin 失效**——程式碼縮排必須用 `x` 位置偏移。詳見 `core/consolas-indent.md`。

⚠️ **程式碼字體大小**:Consolas 12–16pt(等寬字較矮可略小,但 12pt 是下限)。

⚠️ **註解用淺色**:Python `#` 開頭的註解可用 `5C6B5E`(墨綠灰)區隔。
