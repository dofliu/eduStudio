# END 頁 (end-page)

章末儀式頁。**Journal 風格主用**,其他風格可選。

> **狀態**:骨架待補。

---

## 結構元素

- 頁面標題:「E N D · C H A P T E R N」(全大寫 + 大字距)
- 中央引言句(本章核心思想,以引號包覆 + 義大利體)
- 引言下方:作者署名(劉瑞弘 · 國立勤益科技大學 · 智慧自動化工程系)
- 底部小字:作業 / 範例程式提示(可選)

---

## Journal 風格特徵

- **全暗墨綠背景**(與封面一致,形成書本封面 / 封底的閉環感)
- 引言句使用 Noto Serif CJK TC + 大字距 + 引號裝飾
- 強調字用暖金(B8935A)區隔
- **不放雙語頁腳和頁碼**(與封面同規則,保持儀式感)

## 與封面的對稱關係

封面與 END 頁應形成視覺對稱:
- 同樣的深色背景
- 同樣的章節編號字體與字距
- 同樣不放頁腳
- 一個開、一個收,形成「打開書本→闔上書本」的儀式感
