# 練習題頁 / 參考解答頁 (exercise)

題目與解答**分頁呈現**(學術書冊慣例)。

> **狀態**:骨架待補,第五章 PDF 有大量範例可參考。

---

## 結構元素

### 題目頁
- 標題:練習 NN · 主題(例:「練習 01 · 極點判斷」)
- 副標:作答提示(例:「各題 2 分鐘,先自己寫答案,再一起對。」)
- 3–4 題,以卡片或列表呈現
- 每題格式:題號 + 難度標籤(基礎 / 進階 / 挑戰) + 題目 + 提示

### 解答頁
- 標題:練習 NN · 參考解答
- 副標:總結作答關鍵(例:「你答對了嗎?關鍵是「看實部」與「看係數符號」。」)
- 每題對應:Q1 解答 / Q2 解答 / Q3 解答
- 結論句:口訣 / 一句話總結

---

## Journal 風格特徵

- 題目卡片用 card-grid 版型(2×2 或 4×1)
- 題號 Q1 / Q2 / Q3 / Q4 用 Georgia 義大利體大字
- 難度標籤(基礎 / 進階 / 挑戰)用印刷符號區隔
- 解答頁編號 Q1 / Q2 / Q3 用相同色系,以便視覺對應
