# 章節小結 / 整章總結頁 (summary)

兩種使用情境:**每節結尾的「§ X 我們學了…」**,以及**整章結尾的「第 X 章 · 一頁總結」**。

> **狀態**:骨架待補,第五章 PDF 有多個範例可參考。

---

## 兩種變體

### 變體 A:節小結(每節結尾)
- 標題:「§ N 第 N 節我們學了…」
- 副標:「把這四件事裝進口袋,再進入 § N+1 主題。」
- 4–6 個重點條列(編號 01 / 02 / 03…)
- 底部一句話橋接到下一節:「→ 下一節:Routh 先生的神奇表格 …」

### 變體 B:整章總結
- 標題:「§ 第 N 章 · 一頁總結」
- 副標:「從 X 到 Y,從 A 到 B。」
- 依各節整理一個段落(§ 1 …、§ 2 …、§ 3 …)
- 引言收束:書中名句、或一句總結

---

## Journal 風格特徵

- 條列項目用 01 / 02 / 03 編號(Georgia 義大利體、暖金)
- 條列內容字體建議 18pt(Journal 條列下限)
- 引言句用大字 + 引號 + 義大利體(類似 quote-block 但較輕巧)
- 「→ 下一節 …」用箭頭印刷符號
