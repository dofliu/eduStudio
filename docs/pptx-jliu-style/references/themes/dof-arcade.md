# dof-arcade · 街機霓虹 8-bit 風

> DofLab 個人風格 v2 · 深夜霓虹 · 適用於黑客松開幕、技術 demo、開賽動員。
> 視覺氣質：**像 80 年代街機房——CRT 掃描線、霓虹色、像素邊框**。
> 內含 **CSS 動畫**（blink 閃爍），輸出 pptx 時動畫不會保留，僅取靜態畫面。

---

## 何時使用

| 場景 | 是否建議 |
|---|---|
| 黑客松開幕 / 動員 | ✅ 首選 |
| 技術 demo 開場 | ✅ 首選 |
| 程式競賽頒獎 | ✅ |
| LAN party / 內部 game jam | ✅ |
| 正式 conference | ❌ 改 dof-podium |
| 對外品牌簡介 | ❌ 改 dof-supergraphic |

> 與 v1 `dof-shinobi` 的差別：shinobi 是「東方學者氣質的熱血」，arcade 是「西方街機房的玩心」。兩者皆動員場合，但氣質完全不同。

## 色彩 token

| 用途 | Hex | pptxgenjs |
|---|---|---|
| 深夜底 | `#0A0E27` | `"0A0E27"` |
| 深夜底-2 | `#161B40` | `"161B40"` |
| 霓虹青 | `#00F0FF` | `"00F0FF"` |
| 霓虹洋紅 | `#FF006E` | `"FF006E"` |
| 警報橘黃 | `#FFB800` | `"FFB800"` |
| 霓虹綠 | `#39FF14` | `"39FF14"` |
| 紙白前景 | `#F5F5F0` | `"F5F5F0"` |

**用色原則**：
- **永遠深底**（與其他風格區隔最大）
- 一張投影片用 2–3 個霓虹色點綴，避免全頁霓虹（會疲勞）
- 青 = 主標題 / 玩家友善
- 洋紅 = 系統訊息 / 警告
- 橘黃 = HUD / 數值
- 綠 = OK 狀態 / 成功

## 字體

| 用途 | 字體 |
|---|---|
| HUD 與 mono 文字 | **JetBrains Mono** |
| 8-bit 大字 | **Press Start 2P** |
| 中文標題 | **Noto Sans TC 900** |

**鐵則對應**：
- HUD 等 mono 文字 ≥ **18pt**（深底字會視覺收縮）
- 中文標題 96pt，**字重 900**
- Press Start 2P 限用於封面大字 + 頁碼，內文不用（太難讀）

## 頁型骨架

### Cover · INSERT COIN
- 「INSERT COIN TO START」橘黃閃爍（pptx 內無動畫，但保留視覺位置）
- 大字 **Press Start 2P** 168pt 青色，配 4px magenta 偏移文字陰影
- 副標 42pt 橘黃
- 三個 chip：`PLAYERS: 24` `TIME: 36H` `LEVEL: ★★★★☆` 綠色邊框

### Roadmap · SELECT QUEST
- 四個 quest card，每張：
  - magenta 邊框 + magenta 淡背景
  - `LV.01` `LV.02` ... 橘黃 chip
  - 中文標題青色
  - 描述灰白
- 兩欄

### Content · STAGE STATS
- 四個 stat block 橫排：青色邊框 + 青色淡背景
- label 橘黃、val 用 Press Start 2P 48pt 青色、desc 灰白
- 下方加一個「console」框：綠色邊框，mono 文字模擬指令行
  - `> system check` `[OK]` `[!]` 用不同色

### Power-Up / Tips
- 與 Roadmap 同結構，但 chip 改為 `★ ♥ ▲ $` 符號
- 強調「拿到道具」的感覺

### End · GAME OVER
- 居中三行：`GAME / OVER` Press Start 2P 144pt 橘黃
- 四向文字陰影：右下 magenta 4px + 左上青色 -4px
- 下方副標 36pt 青色
- 最下「PRESS ANY KEY TO CONTINUE」綠色閃爍

## 視覺裝飾規範

✅ **允許**：
- CRT 掃描線（每 4px 一條深色橫線）— 強烈建議做成背景 PNG
- 極淡網格背景
- 像素邊框（2px 純色，無圓角）
- 文字四向陰影（製造 3D 偏移感）
- mono 字串與 ASCII 符號 `►` `►` `▲` `★` `♥`

❌ **禁止**：
- 圓角
- 漸層
- 寫實照片
- 人物剪影
- emoji（用 ASCII 符號代替）

---

## 物件最小化策略

- 母片固定 8 個（HUD top × 2、HUD bot × 3、背景網格 PNG、CRT 掃描線 PNG、logo）
- 內容區 5–8 個
- 目標：**≤ 18 個**
- **建議**：把網格 + 掃描線 + 暗影合成一張背景 PNG `arcade-bg.png`，物件數降到 ≤ 12。
