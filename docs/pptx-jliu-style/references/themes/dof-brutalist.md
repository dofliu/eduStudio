# dof-brutalist · 野獸派宣言風

> DofLab 個人風格 v2 · 黑白警示 · 適用於觀點 talk、宣言、批判性演講、call to action。
> 視覺氣質：**像 1970s 政治海報——粗黑、無妥協、有立場**。
> 是 v2 五套裡**最尖銳**的一套，用前請確認你的觀點值得這個包裝。

---

## 何時使用

| 場景 | 是否建議 |
|---|---|
| 觀點 talk / 立場演講 | ✅ 首選 |
| Manifesto / 宣言 | ✅ 首選 |
| 批判性分析 | ✅ |
| Call to action / 動員 | ✅ |
| 中性學術發表 | ❌ 改 dof-podium（這套會搶過內容）|
| 招生 / 對外 | ❌ 改 dof-supergraphic |
| 一般授課 | ❌（學生會疲勞）|

## 色彩 token

| 用途 | Hex | pptxgenjs |
|---|---|---|
| 紙白底 | `#F4F4F0` | `"F4F4F0"` |
| 純黑 | `#0A0A0A` | `"0A0A0A"` |
| 警示橘紅 | `#FF3D00` | `"FF3D00"` |
| 螢光綠 | `#C4FF00` | `"C4FF00"` |
| 灰調次文 | `#555555` | `"555555"` |

**用色原則**：
- 一張投影片**最多 3 色**（黑 + 白 + 警示橘紅）
- 螢光綠保留給「絕對正確」的事（call to action、解答）
- **大量使用反白色塊**（黑底白字、紅底黑字）
- 字級對比要極端：48pt 與 240pt 並存於同一頁

## 字體

| 用途 | 字體 |
|---|---|
| 全部標題 | **Inter** 900 |
| 中文 | **Noto Sans TC** 900 |
| Header/Footer mono | **JetBrains Mono** 500 |

**鐵則對應**：
- 內文 ≥ **20pt**
- 標題 96–220pt
- 封面大字 220–320pt
- 標題**全大寫**，`letter-spacing: -0.04em`
- 中文也用 900 字重，配 sans 才有衝擊力

- 頂部與底部**整條黑色 bar**（不是只有線，是色塊）

## 頁型骨架

### Cover · Manifesto
- 紙白底
- 序號 `A MANIFESTO · NO.07` 28pt 警示紅 letter-spacing 0.3em
- 巨大宣言 Inter 900 **220pt**，可有：
  - `<span class="strike">` 紅色 12pt 刪除線壓字
  - `<span class="box">` 黑底白字色塊壓單字
  - `<span class="alert">` 警示紅單字
- meta footer：6pt 黑線 + 兩段資訊

### Roadmap · Four Arguments
- 大標 Inter 900 132pt，可有黑底白字色塊強調
- 下方四個項目，每項一條**全寬 6pt 黑框**：
  - 左 200px：序號 96pt（黑底白字 / 紅底黑字交替）
  - 右：主標 36pt + 副說明 20pt

### Content · 三欄 Rules
- 大標 132pt，含 alert 詞
- 下方三欄 grid（用 6pt 黑線分隔）：
  - 第 1、3 格：白底
  - 第 2 格：**黑底白字反白**（綠色標號）
- 每格：rule 標號（mono 18pt 紅）+ 標題 38pt + 段落 18pt

### Position · 同 Rules
- 用於結論段，反白格交錯排列

### End · Call to Action
- 整張**黑底**
- 巨大白字 Inter 900 **320pt**
- 關鍵字用警示紅色塊壓字
- 副標螢光綠 mono 22pt
- 頂部 bar 變成**警示紅**底（提示這是高潮）

## 視覺裝飾規範

✅ **允許**：
- 黑底白字反白塊
- 紅色刪除線
- 黑底警示綠字（保留給結論）
- 全大寫英文 + 中文 900
- 6pt 粗黑邊框
- 閃爍紅點（pptx 內取靜態）

❌ **禁止**：
- 圓角（這套是 **0** 圓角）
- 漸層、陰影、發光
- 灰色（除了 footer 用的灰）
- 任何柔和色（粉、淡藍、米色除底紙）
- 人物剪影、emoji、icon
- 襯線字體

---

## 物件最小化策略

- 母片固定 6 個（黑 bar × 2、header/footer text × 4）
- 內容區 5–10 個（卡片框較多時）
- 目標：**≤ 18 個**
- **不建議**用 PNG，因 brutalist 主要靠 Shape + Text 即可表達。
- 注意：roadmap 的「黑色序號方塊」每個都是獨立 Shape，物件數會多一些。
