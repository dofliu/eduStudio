# dof-editorial · 雜誌編輯風

> DofLab 個人風格 · 暖色全襯線 · 適用於業界演講、對外分享、Demo Day、成果展示。
> 視覺氣質：**沉穩、權威、像 TED 但帶印刷品味**。
> 與三條鐵則完全相容（物件最小化 / 字體 ≥18pt / Consolas 用 x 偏移）。

---

## 何時使用

| 場景 | 是否建議 |
|---|---|
| 業界演講 / 對外分享 | ✅ 首選 |
| Demo Day / 成果展示 | ✅ 首選 |
| 招生說明會 / 系所介紹 | ✅ |
| 課程教學 | ⚠️ 偏正式，學生簡報優先用 forest / journal |
| 學術 conference | ⚠️ 改用 dof-podium |
| 讀書會 | ❌ 改用 dof-notebook |

| 用途 | Hex | pptxgenjs |
|---|---|---|
| 紙底（背景） | `#F4EEE3` | `"F4EEE3"` |
| 墨（前景） | `#1E1A14` | `"1E1A14"` |
| 灰調（次文） | `#8A7C65` | `"8A7C65"` |
| 髮絲線 | `#C9BCA3` | `"C9BCA3"` |
| 強調色 · 赭橘 | `#B25530` | `"B25530"` |
| 強調色 · 米金 | `#C9A35B` | `"C9A35B"` |

**用色原則**：
- 紙底是預設背景，**不**用純白
- 赭橘僅用於：英文題眉、序號、極少數圖示
- 米金僅在卡片/分隔頁出現
- 不混用兩種強調色於同一文字

## 字體

| 用途 | 字體 | pptxgenjs `fontFace` |
|---|---|---|
| 中文標題 / 內文 | 思源宋體 / Noto Serif TC | `"Noto Serif TC"` |
| 英文標題 / 序號 / 題眉 | EB Garamond Italic | `"EB Garamond"` |
| 程式碼 | Consolas | `"Consolas"` |

**鐵則對應**：
- 內文 ≥ **20pt**（與 Journal 相同等級，因為襯線字較細）
- 章節標題 **48–60pt**
- 封面大標 **88–100pt**
- 頁碼 / 頁腳 14–16pt（唯一允許 <18pt 的位置）
- Consolas 縮排務必用 `x` 偏移，不要靠空白

## 頁型骨架

### Cover · 章節封面
- **取消母片頂部 logo/章節列**（封面用更大的 logo 在左上）
- 大序號 `Ch. III` 用 EB Garamond italic，**180–200pt**，色 `B25530`
- 章節名 88–100pt
- 副標題 24–28pt，灰
- 一條 2.8" 寬橫線，標題下 0.4"
- 底部仍保留 footer 與「2026 春 · XX 課程」meta 資訊

### Roadmap · 學習地圖
- 題眉 `Roadmap` 英文 italic
- 標題 48–54pt
- 內容區分兩欄 grid，每欄 2 個項目
- 項目格式：`i. 標題 / 副說明`，項目間下 hairline 分隔

### Content · 兩欄 + 引述
- 題眉 `§ III.i · Receptive Field`
- 兩欄等寬，**col-head** 用英文 italic
- 段落字 20–24pt，line-height 1.7
- 底部 pull-quote：左側大引號 `"`（80pt），右側襯線斜體引文

### Code
- 標題下兩欄：左 60% 程式碼，右 40% 說明
- 程式碼底色為「墨色」`#1E1A14`，文字 `#F4EEE3`
- 程式關鍵字用 `#C9A35B`、註解用 65% 白
- 右側「三個容易踩的坑」用 `i. / ii. / iii.` italic 序號

### Exercise
- 大字 `Exercise · 03` 英文 italic，赭橘
- 標題 54pt
- 題幹用襯線中文，前綴 `問題` 英文 italic 灰
- 下方留答案區（橫線 grid，60px 一條）

### Summary
- 題眉 `Recap`
- 三欄並列，每欄頂上加一條 1pt 黑線
- 大序號 `i / ii / iii` 用 EB Garamond italic 56pt，色赭橘
- 子標 36pt、說明 22pt 灰

### End-page
- 母片保留
- 置中大字 `— End —` italic 144pt
- 下方襯線中文金句 44pt
- 最底 italic 英文 `End of Chapter III · Continued in Chapter IV`

## 視覺裝飾規範

- **不**使用 emoji
- **不**使用圖示（icon）；若需要強調，用 hairline + 大序號
- 允許的裝飾：水平髮絲線（1px / 0.75pt）、垂直 rule（限封面與分隔）
- 影像處理：黑白或微暖調濾鏡，**永遠加 1pt 邊框**（色 `C9BCA3`）
- 圖表配色：墨色 + 赭橘為主，米金為次；不使用其他色

---

## 物件最小化策略（策略 B）

每張投影片元素數量目標：**≤ 12 個**
- Logo / 章節 / footer / 頁碼 + 兩條 hairline = 6 個母片固定物件
- 主標題 1、題眉 1、主內容 1–3 = 內容區 3–5 個
- 共 9–11 個

**避免**：
- 不要為 hairline 用 Shape，用 Text + fill 即可
- 不要為「強調色」疊一個 Shape 背景，改用文字色 + 字級對比
- 不要重複擺裝飾用 hairline，每張投影片最多 3 條
