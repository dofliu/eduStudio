# dof-elven · 魔法幻境風

> DofLab 個人風格 · 月光紫 + 燙金 · 適用於理論探索、文學主題、認知科學、哲學講座。
> 視覺氣質：**像古書插畫——靜、深、有月光感，但仍然全襯線、極簡、不戲劇化**。
> 與三條鐵則完全相容。**不繪製人物剪影**——裝飾僅限菱形小星、月暈、燙金細紋。

---

## 何時使用

| 場景 | 是否建議 |
|---|---|
| 認知科學 / 哲學講座 | ✅ 首選 |
| 文學性主題 / 跨領域對談 | ✅ 首選 |
| 理論探索 / 開放性 lecture | ✅ |
| 通識課程 | ✅ |
| 學術 conference | ⚠️ 偏文學，硬技術主題改 dof-podium |
| 競賽 / 動員 | ❌ 改 dof-shinobi |
| 程式設計授課 | ❌ 改 forest |

> 既有 skill 已有 `frieren` 代號，建議：
> - `frieren` 保留為「插畫感、SVG 圖騰、寬版面奇幻」版本
> - `dof-elven` 是「全襯線、極簡、無人物、學者氣質的幻境」版本
> 兩者可並存。

## 色彩 token

| 用途 | Hex | pptxgenjs |
|---|---|---|
| 月光紙底 | `#F2EEF5` | `"F2EEF5"` |
| 墨紫前景 | `#1F1B2E` | `"1F1B2E"` |
| 次文（淡紫灰）| `#9089A4` | `"9089A4"` |
| 髮絲線 | `#D8D2DE` | `"D8D2DE"` |
| 強調色 · 月光紫 | `#7C6FA0` | `"7C6FA0"` |
| 強調色 · 燙金 | `#B89A5C` | `"B89A5C"` |

**用色原則**：
- 紙底**不是純白**，是極淡紫 `F2EEF5`
- 月光紫用於：題眉、序號、標題裝飾、引言
- 燙金僅用於：cover 大序號光暈、菱形小星、書頁頂飾
- 任一張投影片最多 3 色（墨 + 紫 + 金），不超過

## 字體

| 用途 | 字體 |
|---|---|
| 中文標題 | 思源宋體 **300**（細）|
| 中文內文 | 思源宋體 400 |
| 英文 | EB Garamond Italic |
| 序號 | 羅馬數字 `i / ii / iii / iv` 或大寫 `I / II / V`（首選羅馬） |
| 程式碼 | Consolas |

**鐵則對應**：
- 內文 ≥ **22pt**（比 editorial 略大，因為字重輕需要更寬鬆）
- 標題 ≥ **54pt**，字重 **300**
- 標題 `letter-spacing` 設 0.06–0.10em（讓字看起來像「展開的卷軸」）

**和 editorial 的差別**：
- 上下 hairline 改為**點線**或極淡實線（在 pptxgenjs 中用 `dashType: "dash"` 較難，建議改用極淡實線 `D8D2DE`）
- 右上角放一個 700×700px 的**月光紫漸層圓**（極淡，透明度 90%+），需用 PNG
- 章節名前綴可用大寫羅馬數字 `§ V · `

## 頁型骨架

### Cover · 序章封面
- 中央大羅馬數字 `V` 字級 **220pt**，月光紫
  - 數字後方有 360×360 的**金色月暈**（PNG，徑向漸層 22% alpha）
- 標題 116pt，**字重 300**，字距 0.10em
- 副標用斜體中文 32pt 月光紫
- 標題下方一行裝飾：`✦  ◇  ✦  ◇  ✦`（22pt 燙金，字距 0.6em）
- 底部 meta 中名字用月光紫

### Roadmap · 提綱
- 題眉 `Roadmap of Questions`
- 序號 `i / ii / iii / iv` 後接小菱形 `◇`（燙金 0.6em）
- 標題用「今晚的四個提問」這種疑問句

### Content · 兩欄 + 引述
- col-head 用英文 italic + 1pt 月光紫 hairline 下緣
- pull-quote 引號 80pt **月光紫**
- 引述來源 italic 英文 + 自家標籤（`Working notes, DofLab 2026`）

### Code
- 程式碼底色仍是深墨 `#1F1B2E`（與前景反轉）
- 文字 `F2EEF5`
- 關鍵字用燙金 `B89A5C`
- 註解用 45% 月光紙 italic
- 旁邊的「值得發呆的問題」用 `i / ii / iii` italic 序號

### Exercise · A Question to Take Home
- 大字英文 italic 月光紫
- 標題建議**斷成兩行**，留白做留聲感
- 題幹前綴「想想」、「停留」、「試試看」

### Summary · Three Echoes
- 三欄頂線**月光紫**（不是黑）
- 序號羅馬 `i / ii / iii` 月光紫
- 子標精煉、語氣留白

### End-page · ✦ fin ✦
- 大字 `✦ fin ✦` 月光紫 144pt 字重 300
- 金句使用文學性、留聲式語氣
- 底部 italic 英文：`— After [作者名] · [年份]`

## 視覺裝飾規範（最重要）

✅ **允許**：
- 月光紫漸層光環（每張內頁右上一張 PNG）
- 燙金菱形 `◇` 與星 `✦`
- 月光紫 hairline
- 羅馬數字
- 中文襯線斜體（這是 elven 特權）

❌ **禁止**：
- 任何人物剪影、精靈耳朵、魔法陣
- 任何 emoji
- 漸層色塊背景大面積使用
- 飽和度高於 oklch chroma 0.08 的色

---

## 物件最小化策略

- 母片固定 7 個（多了月暈 PNG 1 張）
- 內容區 3–5 個
- 目標：**≤ 12 個**
- **建議**：把「月暈 + 上下 hairline」**預先合成一張 1920×1080 背景 PNG**，命名 `elven-bg.png`。每張 slide 用 `slide.background` 載入，物件數可降到 ≤ 8。
