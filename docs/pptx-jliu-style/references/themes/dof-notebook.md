# dof-notebook · 札記風 / 讀書會

> DofLab 個人風格 · 米黃襯線 + 霧綠霧粉 · 適用於讀書會、輕鬆分享、思考筆記。
> 視覺氣質：**像翻開一本手寫筆記本，但仍然全襯線、不戲劇化**。
> 與三條鐵則完全相容。

---

## 何時使用

| 場景 | 是否建議 |
|---|---|
| DofLab 內部讀書會 | ✅ 首選 |
| 論文輕量分享 / Journal Club | ✅ 首選 |
| 學生 group meeting | ✅ |
| 個人思考整理 / Working notes | ✅ |
| 對外正式演講 | ❌ 改用 dof-podium |
| Demo Day | ❌ 改用 dof-editorial |
| 一般課程教學 | ⚠️ 偏私密，課堂優先用 forest |

## 色彩 token

| 用途 | Hex | pptxgenjs |
|---|---|---|
| 米黃紙底 | `#F1ECE3` | `"F1ECE3"` |
| 墨 | `#2A2520` | `"2A2520"` |
| 次文灰褐 | `#9C948A` | `"9C948A"` |
| 髮絲線 | `#D6CFC1` | `"D6CFC1"` |
| 強調色 · 苔綠 | `#6E7E62` | `"6E7E62"` |
| 次強調 · 粉藕 | `#B89A92` | `"B89A92"` |
| 札記橫線（極淡苔綠 7% alpha）| `rgba(110,126,98,0.07)` | n/a，pptxgenjs 用 `D8D5CC` 替代 |

**用色原則**：
- 苔綠 = 「眉批」與序號的顏色
- 粉藕 = 日期標記點、引用標籤、心情提示
- 一張投影片**最多兩個強調色一起出現**

## 字體

| 用途 | 字體 |
|---|---|
| 中文 | 思源宋體 / Noto Serif TC |
| 英文 / 序號 / 日期 | EB Garamond Italic |
| 程式碼 | Consolas |

**鐵則對應**：
- 內文 **20–24pt**
- 章節標題 **52–72pt**
- 封面大標 **88–112pt**

**特殊**：
- 中文序號可用 `一 / 二 / 三 / 四` 帶前綴點（`·一`、`·二`），呼應筆記感
- 引言可加 italic（中文襯線斜體在 Noto Serif TC 仍可讀）

```
│ DofLab                          No. 07 · 札記章節名稱     │  y=0.18"
│ ──────────────────────────────────────────────────────── │  y=0.34"
│                                                          │
│   · · · · · · · · · · · · · · · · · · · · · · · · · ·    │  ← 極淡橫線
│                                                          │  （每 0.5"
│   · · · · · · · · · · · · · · · · · · · · · · · · · ·    │   一條）
│                                                          │
│   · · · · · · · · · · · · · · · · · · · · · · · · · ·    │
│                                                          │
│ ──────────────────────────────────────────────────────── │  y=6.97"
│ 劉瑞弘 · 智慧自動化工程系 · NCUT · DofLab        20 / 25 │  y=7.10"
└──────────────────────────────────────────────────────────┘
```

**和前兩個的差別**：
- **內頁底有極淡水平線**（札記紙感）
- 章節列改稱 `No. 07 · XXX`，類似 Notebook 編號
- footer 同 editorial（中文版）

**座標表**

| 元素 | x | y | w | h | 字級 |
|---|---|---|---|---|---|
| Logo | 0.50 | 0.18 | 1.5 | 0.28 | 14 |
| Notebook label (右上) | 7.50 | 0.18 | 5.33 | 0.28 | 11 |
| 上 hairline | 0.50 | 0.34 | 12.33 | 0.01 | – |
| 札記橫線 × N | 0.83 | y_n | 11.67 | 0.005 | – fill `D8D5CC` |
| 下 hairline | 0.50 | 6.97 | 12.33 | 0.01 | – |
| Footer | 0.50 | 7.10 | 8.00 | 0.25 | 10 |

| 標題區 | 0.83 | 0.95 | 11.67 | 1.40 | 52–72 |

**札記橫線生成（pptxgenjs）**

```javascript
// 在內容區內每 0.5" 加一條極淡水平線
for (let y = 1.5; y < 6.7; y += 0.5) {
  slide.addText("", {
    x: 0.83, y: y, w: 11.67, h: 0.005,
    fill: { color: "D8D5CC" },
  });
}
```

## 頁型骨架

### Cover · 札記封面
- 取消頂部 hairline（封面更安靜）
- 日期 mark：`● 2026 · 03 · 14 · Saturday Afternoon`
  - 圓點用粉藕色 `B89A92`，10×10px
  - 後接日期 italic 28pt
- 編號 `Notebook No. 07` italic 苔綠 48pt
- 大標 88–112pt
- 副標 italic 苔綠 32pt
- 底部 meta：「與會：XXX · 地點 R503」+ 「瑞弘 記」

### Roadmap · 今天的提綱
- 題眉 `Today's Notes`
- 標題用親近語氣：「今天想聊的四件事」
- 兩欄 grid，序號用 `·一 / ·二 / ·三 / ·四`（中文點序）
- 每項主標 + 一行說明（語氣比 editorial 鬆）

### Content · 兩欄 + 眉批
- col-head：左「Marr 怎麼說」、右「我的眉批」
- 圖示位置可以放手繪 sketch placeholder
- 引述用 italic + 自己的讀書筆記日期作為來源
  - 例：`— 我的讀書筆記，2026.03.14`

### Code
- 程式碼仍用深底 `#2A2520` + 米黃字 `#F1ECE3`
- 註解可以是「自己對自己說的話」風格
  - 例：`# Marr 等了 40 年才看到這個`
- 旁邊「討論問題」用 `·` 點列，不用編號

### Exercise · Open Question
- 大字 `Open Question` italic 苔綠
- 標題用對話語氣：「下次聚會前的小作業」
- 題幹前綴用「想想看」灰

### Summary · 今天的回頭看
- 題眉 `Closing Notes`
- 三欄、頂上 1pt 黑線
- 序號 `·一 / ·二 / ·三` 苔綠 56pt
- 子標精煉至 4–8 字

### End-page · — fin —
- 大字 `— fin —` italic 144pt 苔綠
- 金句 44pt
- 底部下次札記預告：`Next Notebook · No. 08 · 2026.04.18`

## 視覺裝飾規範

- **唯一允許的裝飾**：札記橫線（極淡）、粉藕圓點 mark、苔綠細節
- **不**使用 emoji / icon
- 圖表配色：墨 + 苔綠為主，粉藕為輔，髮絲為網格
- 引言可加 italic 中文，這是 notebook 的特權（其他兩風格不用）

## 物件最小化策略

每張內頁因為要加札記橫線，物件數量略多：**目標 ≤ 18 個**
- 母片固定 6 個
- 札記橫線 6–10 條（最節省做法：把它們合成一張背景圖 PNG 載入，這樣只算 1 個）
- 內容區 3–5 個

**建議**：把札記橫線預先做成一張 1920×1080 的 PNG 背景，命名 `notebook-paper.png`，每張投影片用 `slide.background = { path: ... }` 載入。這樣物件數可控制到 ≤ 10。
