# dof-shinobi · 忍者熱血風

> DofLab 個人風格 · 深夜墨底 + 朱印紅 · 適用於實作競賽、動員會、出陣前的熱血講話。
> 視覺氣質：**沉穩中帶熱度，像深夜書房裡剛蓋下的那枚朱印**。
> 與三條鐵則完全相容。**不繪製人物剪影**——裝飾僅限朱印、筆觸、捲軸邊飾。

---

## 何時使用

| 場景 | 是否建議 |
|---|---|
| 黑客松 / 實作競賽動員 | ✅ 首選 |
| 專題期初動員 / 出陣前演講 | ✅ 首選 |
| 學生競賽戰前簡報 | ✅ |
| 一般授課 | ⚠️ 太強烈，學生會疲勞 → 改 forest |
| 學術 conference | ❌ 改 dof-podium |
| 對外正式分享 | ❌ 改 dof-editorial |

> 既有 skill 已有 `naruto` 代號，建議：
> - `naruto` 保留為「漫畫感、活潑、SVG 圖騰」版本
> - `dof-shinobi` 是「全襯線、極簡、無人物、學者氣質的熱血」版本
> 兩者風格交集低，可以並存於同一 skill。

## 色彩 token

| 用途 | Hex | pptxgenjs |
|---|---|---|
| 墨夜底 | `#16110A` | `"16110A"` |
| 紙黃前景 | `#F2E5C8` | `"F2E5C8"` |
| 次文（暗黃褐）| `#8A7D5E` | `"8A7D5E"` |
| 髮絲線 | `#3A3024` | `"3A3024"` |
| 強調色 · 朱印紅 | `#C73A1D` | `"C73A1D"` |
| 強調色 · 焰橘 | `#E89030` | `"E89030"` |

**用色原則**：
- 全程**深底淺字**（與其他四套差異最大）
- 朱印紅僅用於：印章、左側筆觸、序號、重點符號
- 焰橘是「副標題與英文題眉」的專屬色
- **不**混用兩個強調色於同一段文字

## 字體

| 用途 | 字體 |
|---|---|
| 中文標題 | 思源宋體 **700**（比其他風格更粗）|
| 中文內文 | 思源宋體 400 |
| 英文 | EB Garamond Italic |
| 序號 | 中文壹貳參肆 / 英文 italic 皆可 |
| 程式碼 | Consolas，底色 `#0A0805` |

**鐵則對應**：
- 內文 ≥ **20pt**
- 標題 ≥ **54pt**，建議用 700 weight
- 因為深底字會視覺收縮，**字級可以比 editorial 大 10%**

│ │                                                        │     朱筆豎線
│ │        ★ 內容區（x: 1.20"–12.50", y: 0.95"–6.55")       │     y=0.9–6.6
│ │                                                        │
│ │                                                        │

**和 editorial 的差別**：
- 全張**深底** `16110A`
- 文字色全部改成 `F2E5C8`
- **左側 4px 朱筆豎線**（從 y=0.9 到 y=6.6，做漸層淡出兩端）
- 上下 hairline 顏色改為暗色 `3A3024`

## 頁型骨架

### Cover · 出陣封面
- **朱印 stamp**：220×220 圓形雙線框（內外間距 8px），內含：
  - 大字「壹 / 貳 / 參」中文，88pt 朱紅
  - 下方「啟 程 / 行 軍 / 出 陣」標籤 18pt 朱紅 0.3em 字距
- 標題用 124pt **粗襯線**
- 副標用焰橘 36pt
- 底部 meta 中「劉瑞弘」名字用焰橘色

### Roadmap · 戰術地圖
- 題眉用英文 `Mission Map`
- 序號用中文「壹貳參肆」（呼應 cover 朱印）
- 每項主標 + 一行副說明
- 兩欄分隔線改用暗紅 `3A3024`

### Content
- 與 editorial 同構，但深底
- placeholder 邊框改 `3A3024`，內網格 14px 斜紋
- pull-quote 引號 80pt 朱紅
- 引述來源建議用「DofLab 戰前訓示 / 戰術手記」這類自家味語氣

### Code
- 程式碼底色 `#0A0805`（比頁面底還深）
- 1px `3A3024` 外框
- 關鍵字用焰橘 `E89030`
- 註解用 45% 紙黃 italic

### Exercise · Tactical Drill
- 大字 `Tactical Drill · 01` 英文 italic 朱紅
- 標題保留兩行斷句，可帶問句
- 題幹前綴用「情境」灰

### Summary · Three Vows
- 三欄頂線改朱紅 `C73A1D`（比其他風格更醒目）
- 序號用「壹貳參」朱紅
- 標題建議 ≤ 8 字，動詞句

### End-page · 出陣
- 大字 `— 出 陣 —` 朱紅 144pt
- 金句保留沉穩語氣（避免戲劇化）
- 底部 italic 英文預告 / 行動呼籲

## 視覺裝飾規範（最重要）

✅ **允許**：
- 左側朱筆豎線（每張內頁）
- 圓形朱印（封面、節分隔）
- 暗紅水平 hairline
- 中文大字「壹貳參肆」作為序號
- 焰橘漸層光暈（封面右下角，極淡）

❌ **禁止**（沿用既有 frieren/naruto 規則）：
- 任何人物剪影
- 任何 emoji
- 動漫畫風的閃電線、效果線
- 飽和度過高的色塊（不是日漫色票）

---

## 物件最小化策略

- 母片固定 8 個（多了朱筆豎線 1–3 段、上下 hairline 各 1）
- 內容區 3–5 個
- 目標：**≤ 14 個**
- **建議**：把朱筆豎線 + 紙紋背景**預先合成 PNG**，命名 `shinobi-bg.png`，每張 slide 用 `slide.background = { path: ... }` 載入，物件數可降到 ≤ 10。
