# dof-supergraphic · Pentagram 大色塊瑞士幾何風

> DofLab 個人風格 v2 · 巨大色塊 + Helvetica 風格 · 適用於品牌簡介、合作案、招生大型場合。
> 視覺氣質：**像 Pentagram / Massimo Vignelli 1970s 海報——克制、巨大、有結構**。
> 撞色但理性，與 dof-zine 的「DIY 印刷感」拉開距離。

## 色彩 token

| 用途 | Hex | pptxgenjs |
|---|---|---|
| 純白 | `#FFFFFF` | `"FFFFFF"` |
| 純黑 | `#000000` | `"000000"` |
| 撞色紅 | `#E63946` | `"E63946"` |
| 撞色藍 | `#1D4ED8` | `"1D4ED8"` |
| 撞色黃 | `#FFD60A` | `"FFD60A"` |
| 灰調次文 | `#6B6B6B` | `"6B6B6B"` |

**用色原則**：
- 一張投影片**最多 3 種色塊**（包含白色）
- 大型色塊應佔畫面 40% 以上面積
- 色塊之間用**4pt 純黑線**分隔
- 標題大字一律黑色，關鍵字可改紅色（單一強調）

## 字體

| 用途 | 字體 |
|---|---|
| 全部 | **Inter** 900 (Helvetica Neue 替代) |
| 中文 | **Noto Sans TC** 900 |
| Footer/Header mono 風 | Inter 500 letter-spacing 0.12em uppercase |

**鐵則對應**：
- 內文 ≥ **22pt** Inter 400
- 標題 96–140pt Inter 900
- 封面大數字 400pt 以上
- 字距 `letter-spacing: -0.04em`（瑞士幾何招牌特徵）

- 上下都是**粗 4pt 黑線**（不是 hairline）

## 頁型骨架

### Cover · 半分色塊
- **左 5fr 紅色塊**（佔畫面 41%）：
  - 頂部 label `DofLab / 2026` 18pt 白
  - 中央巨大數字 `26` Inter 900 **400pt** 白
  - 底部 meta 18pt 白
- **右 7fr 白色塊**：
  - 大標 Inter 900 140pt 黑
  - 副標 30pt 灰
  - 底部「BY ...」18pt 黑，上方加 4pt 黑線

### Roadmap · Sections
- eyebrow `SECTIONS` 紅
- 大標 132pt
- 四個項目橫排，每項：
  - 序號 72pt（紅 / 藍 / 黑 / 黃描邊）
  - 主標 38pt Inter 800
  - 右側 label `FOCUS · WHERE` 18pt 灰 uppercase
  - 下方 2pt 黑線

### Content · 雙欄 + Stat Bar
- 兩欄段落 28pt
- 下方 stat bar：四格平均分，分別用 白/黃/藍/黑 不同底色
  - 數值 96pt Inter 900
  - label 18pt 600

### Stats · 同 Content
- 突顯數字，少文字

### End · 三段橫帶
- 頂部黑色帶 1fr
- 中央白色 4fr：巨大標題 240pt
- 底部紅色帶 1fr

## 視覺裝飾規範

✅ **允許**：
- 大型純色色塊
- 4pt 純黑分隔線
- 數字用色塊邊框 hollow（如 `-webkit-text-stroke: 2px black; color: yellow`）
- 標題關鍵字單一變紅

❌ **禁止**：
- 圓角（這套是 **0** 圓角）
- 漸層
- 陰影
- 第四種色（最多三色含白）
- 襯線、手寫、mono
- 人物剪影、emoji

---

## 物件最小化策略

- 母片固定 5 個（header、上下粗線、footer × 2）
- 內容區 4–8 個
- Cover 是色塊主導，物件少（左 1 塊 + 3 段文字、右 4 段文字）= 8 個
- 目標：**≤ 14 個**
- **不建議**用 PNG 背景，色塊用 Shape 即可（Shape 在 pptx 比 PNG 好編輯）
