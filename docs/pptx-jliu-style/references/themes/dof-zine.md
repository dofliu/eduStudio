# dof-zine · 獨立雜誌海報風

> DofLab 個人風格 v2 · 撞色撞排版 · 適用於年度回顧、宣言式 talk、重磅發表。
> 視覺氣質：**像一本紙本獨立雜誌的封面——大字、撞色、印刷感**。
> **不適合**正式學術場合（會搶過內容）。

---

## 何時使用

| 場景 | 是否建議 |
|---|---|
| DofLab 年度回顧 / 出刊 | ✅ 首選 |
| 重磅發表 / Manifesto talk | ✅ 首選 |
| 招生說明（活潑場） | ✅ |
| 黑客松開幕 | ⚠️ 改 dof-arcade |
| Conference / Keynote | ❌ 改 dof-podium |
| 一般授課 | ❌ 太強烈 |

## 色彩 token

| 用途 | Hex | pptxgenjs |
|---|---|---|
| 紙白底 | `#FAFAF5` | `"FAFAF5"` |
| 黑墨 | `#0A0A0A` | `"0A0A0A"` |
| 螢光黃 | `#FFE800` | `"FFE800"` |
| 撞色紅 | `#E63946` | `"E63946"` |
| 撞色藍 | `#1D4ED8` | `"1D4ED8"` |
| 灰調次文 | `#777067` | `"777067"` |

**用色原則**：
- 任一張投影片**至少出現黃、紅、黑、白其中三色**
- 紅色用於：印章式 eyebrow、序號、撞色色塊
- 黃色用於：highlight、cover ribbon、大背景色塊
- 藍色為輔色，僅在標題裡點綴
- **可以**色塊壓字、字超出畫面、傾斜 ±2°

## 字體

| 用途 | 字體 | 字重 |
|---|---|---|
| 巨大標題 | **Archivo Black** / Inter 900 | 900 |
| 中文標題 | **Noto Sans TC 900** | 900 |
| 內文 | Inter | 400 / 700 |
| 章節編號 / 小字 | JetBrains Mono | 500 |

**鐵則對應**：
- 內文 ≥ **18pt**（撞色背景下要更黑、字級略大）
- 標題 **96–140pt**，封面可到 **280pt**
- 不用襯線體（zine 與 v1 五套襯線家族刻意拉開）

│      ★ 內容區（x: 0.55"–12.78", y: 1.0"–6.4")             │
│                                                          │
│                                                          │

**和 editorial 的核心差別**：
- 頂部不用 hairline；改用「logo + 黃色 ribbon issue tag」
- 底部用**粗 2pt 黑線**（不是 hairline）
- 字體系統完全切換到 sans
- 標題可以**溢出版心**製造視覺張力

## 頁型骨架

### Cover · Zine 封面
- **半張黃色色塊**（y: 30%–90%）橫向覆蓋整個畫面
- 頂部 issue line：左右兩格資訊 + 一條 3pt 黑線分隔
- 巨大標題 240–280pt，可破出版心
- 標題中關鍵字用**紅色色塊壓字**+ 旋轉 -2°
- 副標 32pt 黑色，最多兩行

### Roadmap · Table of Contents
- eyebrow 改為「`CONTENTS`」chip 樣式（紅框）
- 標題巨大，中可有**黃色 highlight 與藍色詞**
- 兩欄四個項目：左序號（紅）+ 主標 + 副說明，底下粗 2pt 黑線

### Content · Feature
- eyebrow 「FEATURE STORY」紅框
- 標題大字 + 黃色 highlight
- 下方三張卡片：
  - 卡片 01：黃底
  - 卡片 02：白底 + Y 偏移 +20px（錯位）
  - 卡片 03：黑底白字 + Y 偏移 -12px

### Quote / Voice
- eyebrow 「QUOTE OF THE YEAR」紅框
- 巨大標題 + highlight
- 下方黑底白字 quote-block：左側 200pt 黃色引號 `"` + 引言 + 來源（mono italic 黃）

### End-page · Back Cover
- 整張**黑底**
- 巨大黃字三行：`THANKS / FOR ALL / THE BUGS.`
- 副標白字
- 頂部 logo 改白字、issue tag 不變

## 視覺裝飾規範

✅ **允許**：
- 色塊壓字（紅色塊 + 白字、黑色塊 + 黃字）
- 文字旋轉 ±2° 製造手作印刷錯位
- 卡片 Y 軸 ±10–25px 錯位
- 粗黑邊框 3pt
- 黃底紅字 / 黑底黃字的大膽撞色

❌ **禁止**：
- 圓角（這套是 0 圓角）
- 漸層
- 陰影（除非是印刷感 offset）
- emoji
- 人物剪影

---

## 物件最小化策略

- 母片固定 5 個（logo + issue chip + 粗線 + footer × 2）
- 內容區 5–8 個
- 目標：**≤ 15 個**
- **建議**：色塊背景（半張黃、半張紅）可預先合成為一張背景 PNG，物件數降到 ≤ 10。
