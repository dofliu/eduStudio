## 設計哲學

適用實作專題、競賽激勵、團隊合作。

⚠️ **依賴**:需要 `npm install -g sharp`(SVG → PNG 轉換)。JS 主程式須使用 **async/await**。
⚠️ **裝飾元素是道具/圖騰/符號,不繪製人物剪影**。
